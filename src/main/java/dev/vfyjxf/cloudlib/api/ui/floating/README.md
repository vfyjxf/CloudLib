# Floating Positioning System

This package provides a middleware-based positioning engine for anchoring floating
widgets (tooltips, popovers, dropdowns, etc.) relative to reference widgets.

## Origin

The design and algorithms in this package are ported from
[floating-ui](https://github.com/floating-ui/floating-ui), a JavaScript library
for positioning floating elements. The original source is licensed under the MIT
License — see the [LICENSE](LICENSE) file in this directory.
